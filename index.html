About The CVE Desk

The CVE Desk is the application-security desk in Bishow Pandey's network — fitting, since application security is his day job. A scanner reads the NVD's recent publications, cross-checks them against CISA's known-exploited catalog, asks FIRST's EPSS model how likely each flaw is to be exploited, and pulls ecosystem and package data from the GitHub Advisory Database. It then draws the result as a graph, because a vulnerability is never just a row in a table: it is a weakness, in a product, in an ecosystem, with a blast radius.

How to use it: start with the red board (KEV), then sort your patch queue by CVSS × EPSS, and glance at the graph to see which weakness families keep coming back — that recurring CWE is tomorrow's headline.

Good to know: vulnerability data comes from the NVD (NIST), CISA, FIRST and GitHub, and is summarized for awareness. Scores change as analysis matures; a CVE marked "awaiting analysis" may gain its CVSS days later. Always confirm details and remediation in the official record and your vendor's advisory before acting. This desk is information, not a patch-management service.
